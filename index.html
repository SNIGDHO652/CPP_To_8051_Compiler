What the Tomasulo tab means

            

                The simulator treats compiler temporaries and local variables
                as logical registers on a hypothetical out-of-order machine.
                It shows reservation stations, producer tags, operand wake-up,
                issue, execute and one-result-per-cycle common-data-bus writeback.
            

            

                Simulation is performed one basic block at a
                time because compile time does not know which runtime branch is
                taken or how many times a loop iterates.
            

        


        

            
8051 target model

            

                Variables use internal RAM 30H-6FH.
                The generated program initializes SP=6FH,
                leaving 70H-7FH for expression temporaries.
            

            

                The scheduler never moves operations across labels, branches,
                returns or writes to P0-P3.
