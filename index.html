Target model

            

                Variables use internal RAM 30H-6FH.
                The generated program initializes SP=6FH,
                leaving 70H-7FH for temporary expression values.
            

            

                Values are unsigned 8-bit integers. Arithmetic wraps modulo
                256. Full C++ features such as classes, pointers, templates,
                arrays, exceptions, STL and user-defined functions are
                intentionally outside the project scope.
